# CodeFlow

Interactive diagrams of how your code flows, shown beside the code.

This build has the CodeFlow activity-bar view, an interactive diagram of the workspace graph, and caller and callee counts above each function. Click a node to open that symbol. **CodeFlow: Show Flow for Symbol at Cursor** draws the neighbourhood of the symbol under the cursor. **CodeFlow: Show Trait Map** draws a Rust trait and its impls, or a type and the traits it implements. Uncertain calls are drawn dashed.

Open the Command Palette and run **CodeFlow: Open Diagram**.

Development, packaging, and the roadmap are documented in the [project README](https://github.com/rezis-work/codeflow#readme).
